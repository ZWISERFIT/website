安装

# Python 3.9+ · 当前版本，从源码安装 pip install git+https://github.com/ZWISERFIT/lao.git

PyPI 上目前是 0.1.0——没有 CLI 的早期版本。PyPI 更新前，当前版本从源码安装。

或者克隆：

git clone https://github.com/ZWISERFIT/lao.git cd lao && pip install .

GitHub: ZWISERFIT/lao →

快速上手

# 初始化 LAO runtime lao init # 用你自己的话记录一条 Trust Event lao trust-event --type success --desc "..." --evidence "..." # 亲手重算台账哈希 lao verify # 查看锚定状态 lao status

组件自身零 LLM 调用：你用自己的 key 部署它，我们永远不在你的 token 里抽成。
