1. LAO 是什么

LAO（Lineage Anchored Ontology）是一个位于 LLM 与 Runtime 之间的独立组件。它按任务选择正确的模型，通过缓存感知路由减少浪费的 token，并用主人自己的经验校准回答。它自身零 LLM 调用。它免费、开源（Apache 2.0），不从你的 token 支出中抽取任何分成。

  • 位置：位于 LLM 与 Runtime 之间——它包裹你现有的调用，不替代它们。
  • 激励对齐：不从任何 token 中获得报酬；它的价值度量是你省下的成本。
  • 遥测：当前版本没有任何遥测（见隐私页）。
  • 许可证：Apache 2.0——代码公开、可审计、可 fork。

2. 如何安装

# Python 3.9+ pip install lao-human-calibration # 或从源码 git clone https://github.com/ZWISERFIT/lao.git cd lao && pip install .

自带你的模型 API key。LAO 自身不发起任何 LLM 调用；所有推理成本都留在你自己的账户上。

3. 接口面

核心入口（稳定接口面；完整参考见仓库 README）：

接口面模块用途
路由 / 模型选择lao.effect_anchored.routing.model_router按任务匹配模型，安全 → 速度 → 成本三级过滤；缓存感知的请求优化。
意图锁（请求侧）lao.effect_anchored 意图校验优化表述，不改变意图。
经验锚（回答侧）lao.effect_anchored.cognitive_anchor用主人的事实校准 LLM 输出；校准失败时如实回退到原始回答。
记忆链lao.core行为记忆：身份、约束、偏好跨会话持久。
