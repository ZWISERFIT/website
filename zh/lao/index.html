LAO 如何省下你的 token

LAO — Lineage Anchored Ontology。位于你的 LLM 与 Runtime 之间的独立组件。LLM 保持聪明；LAO 让它诚实——并且便宜。

三层结构

L1

模型选择 · 每个任务的最优价值

安全优先：不合适的模型先排除 再看速度 再看成本 缓存感知的请求优化
输出：这个任务，对的模型，对的价格。
L2

经验流水线 · 你的记忆

经验在你工作时沉淀 错误变成永久约束 上下文修剪到关键锚点 每一步都征得许可
输出：结构化、可复用的经验——永远属于你。
L3

回答校准 · 绝不虚张声势

意图锁：你的本意永不被改变 回答用你的事实校准 校准失败 → 如实回退到原始回答
输出："可能对"变成"对着你的经验而言是对的"。
