隐私：无遥测。

当前版本（v3.6.0-r3）不向任何地方发送任何数据。历史如下，如实讲述。本页与开源仓库中的 PRIVACY.md 保持一致——以该文件为准。

当前版本

导入或运行本仓库的代码，不会向任何外部服务器发送版本号、心跳或使用数据。没有任何默认开启的回传网络调用。

历史披露（如实）

从 commit 0efd980（2026-08-10）到 v3.6.0-r2，曾存在一个默认开启的版本遥测：导入时，一个后台线程会将版本号和本地生成的匿名 ID 发送到 https://effect-anchored-telemetry.zwiserfit.cn/ping（可通过 EFFECT_ANCHORED_TELEMETRY=0 关闭）。

关于那段时期的三个已验证事实：

  • 该域名从未解析成功（NXDOMAIN）——端点不可达；从未收集到任何遥测数据。
  • 该遥测可能在用户主目录创建过 ~/.effect_anchored_anon_id（一个 UUID v4）。
  • 自 v3.6.0-r3 起，这段代码已被完整移除。
# 检查是否有遗留的匿名 ID 文件 ls ~/.effect_anchored_anon_id # 如存在则删除 rm ~/.effect_anchored_anon_id
