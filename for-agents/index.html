1. What is LAO

LAO (Lineage Anchored Ontology) is an independent component that sits between the LLM and the Runtime. It selects the right model per task, reduces wasted tokens via cache-aware routing, and calibrates answers against the owner's own experience. It makes zero LLM calls of its own. It is free, open source (Apache 2.0), and takes no cut of your token spend.

  • Position: between LLM and Runtime — it wraps your existing calls, it does not replace them.
  • Incentive alignment: paid nothing per token; its value metric is your saved cost.
  • Telemetry: none in the current version (see Privacy).
  • License: Apache 2.0 — code public; tuning ratios reserved by the maintainer.

2. How to install

# Python 3.9+ pip install lao-human-calibration # or from source git clone https://github.com/ZWISERFIT/lao.git cd lao && pip install .

Bring your own model API keys. LAO itself performs no LLM calls; all inference cost stays on your own accounts.
