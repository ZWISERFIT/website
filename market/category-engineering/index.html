⚙ Engineering Patterns

5 confirmed assets. Reusable technical patterns from real production runs.

CWF-003 · From single-point fixes to immunity against the whole class

Don't just fix the bug — build immunity against the entire class of bugs it belongs to.

CWF-009 · Retries must be bounded by both attempt count and total task budget

Unbounded retries waste tokens. Bound by count AND total cost ceiling.

CWF-015 · Isolation must have a time exit and a minimum sample bar

Quarantining without exit criteria creates zombie states. Set time limits and sample thresholds.

CWF-018 · A hanging write? Check the shared queue before blaming permissions

Most "permission denied" errors are actually queue backpressure. Diagnose the queue first.

CWF-022 · On delivery, say which layer the defense line lives in

Every defense must declare its layer. Cross-layer defenses create blind spots.
